# Changelog

## v1.0.0 - 2026-09-28

- Defined the first stable public-code version of the CT-based delayed hemothorax prediction pipeline.
- Public repository includes DICOM preprocessing/QC, lung and rib segmentation workflow, H5 dataset preparation, 2D MIL training, 3D CNN baseline training, and rib-fracture feature analysis.
- Clinical images, patient-level labels, model checkpoints, and other protected data remain excluded.
